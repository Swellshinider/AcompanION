# Security

AcompanION reads game traffic passively and stores character data locally. If you find a vulnerability (for example in how it loads Npcap, handles saved files or processes malformed packets), report it privately through GitHub's [security advisories](https://github.com/Swellshinider/AcompanION/security/advisories/new) instead of a public issue.

Never share packet captures or the state files (`characters.json`, `meter.json`) in a report: they contain account data.
