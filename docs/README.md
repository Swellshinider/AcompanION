# Documentation index

| Document | What it is | Keep updated when |
|---|---|---|
| [status.md](status.md) | Where things stand, what is not verified, known limits, next steps | End of every session |
| [development.md](development.md) | Setup, `task` shortcuts, capture workflow, game data, translations | Commands or workflow change |
| [architecture.md](architecture.md) | Pipeline, modules, state and threading model | A module, boundary or data flow changes |
| [protocol.md](protocol.md) | Wire protocol findings with evidence | A finding is confirmed or disproved |
| [decisions.md](decisions.md) | Decision log with rationale | A decision is made or changed |
| [patch-notes.md](patch-notes.md) | What changed for players, the source of the release notes | Every commit that changes something a player can notice |

Conventions:

- Docs are in English. No account data, tokens, character names or raw capture bytes in any document; use placeholders.
- `status.md` is allowed to be opinionated and short; the other documents are reference.

Agents: start at [../AGENTS.md](../AGENTS.md).
